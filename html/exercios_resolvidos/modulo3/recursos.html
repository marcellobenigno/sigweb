Portais de Dados Abertos

  • IBGE — Downloads de Geociências — Malhas territoriais, limites municipais, estaduais e setores censitários.
  • ANA — HidroWeb — Série histórica de dados fluviométricos e pluviométricos de todo o Brasil.
  • MapBiomas — Coleções de Uso e Cobertura do Solo — Mapeamento anual do Brasil de 1985 a 2023 em resolução de 30 m.
  • INDE — Catálogo de Metadados — Repositório nacional de dados geoespaciais governamentais padronizados pelo OGC.

Serviços WMS Públicos

  • INPE — WMS GetCapabilities — Imagens de satélite e produtos do programa PRODES/DETER para monitoramento do desmatamento.
  • IBGE GeoServer — WMS — Malhas territoriais, setores censitários e limites administrativos em formato WMS.

Ferramentas e Softwares

  • QGIS — Software SIG de Código Aberto — Sistema de Informação Geográfica desktop para análise, edição e visualização de dados espaciais.
  • Leaflet.js — Biblioteca JavaScript para mapas interativos — Biblioteca leve e extensível para criar visualizadores WebGIS no navegador.
  • W3C HTML Validator — Validador oficial de código HTML do consórcio W3C.
